TEE TIME COMPANION — STARTER PWA

This is an iPhone-friendly installable web-app starter. It currently provides:
- The agreed Friday/Saturday 6pm schedule and 8-day target date calculation.
- Your 1-player, 9–10am, earliest-time preferences.
- A direct link to the supplied Chronogolf widget.
- Basic offline caching for the app shell.

IMPORTANT: It does NOT yet query live Chronogolf availability, run scheduled cloud checks, send push notifications, or book. It does not store Chronogolf credentials. Live checking requires a supported/authorised Chronogolf integration or an approved club/platform mechanism. Do not add your password to these files.

TO INSTALL ON IPHONE:
1. Host this folder on an HTTPS static host (for example, a static site host).
2. Open the hosted address in Safari on iPhone.
3. Tap Share > Add to Home Screen.

Files: index.html, manifest.webmanifest, sw.js, icon.svg.
